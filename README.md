# 瞬贴 PasteFlick

瞬贴是为 Apple 芯片 Mac 打造的原生剪贴板管理器。它在菜单栏后台记录复制历史，按 **⌃⌥V** 就能打开搜索，选中后按回车贴回刚才的位置。

## 主要特性

- **安装包小。** 当前自用候选包压缩后约 **317 KiB**，包含应用和图标。
- **后台占用低。** 在 Apple M1 Pro 上，Release 构建保留 300 条混合历史，在稳定空闲时连续采样 5 分钟，内存峰值 **15.19 MB**，CPU 平均占用 **0.0021%**。
- **查找和粘贴快。** 快捷键打开历史后可直接打字，结果随输入更新。上下键选中，回车粘贴，整个过程都能用键盘完成。
- **历史只存本机。** 瞬贴无需账号，记录、搜索、预览和粘贴均在本机处理，无云端同步。来源明确标记为敏感的内容会跳过保存。复制文件或文件夹时，只记录原位置。
- **Apple 原生。** 使用 Swift 和 AppKit 开发，只依赖 macOS 系统框架。后台运行时入口在菜单栏，Dock 不显示图标。

## 怎么用

1. 照常用 **⌘C** 复制文字、链接、图片或文件。瞬贴会保留来源提供的富文本样式，最多保存 300 条、合计 1 GB，退出重开后仍可找回。
2. 按 **⌃⌥V** 打开历史面板。输入关键词可查找文字、链接和文件名。在列表中按 **← / →** 切换类型，按 **空格** 预览选中项。
3. 按 **回车** 粘贴。自动粘贴需要在 macOS 的「隐私与安全性 → 辅助功能」中授权。未授权时，瞬贴会把选中内容放回系统剪贴板，可手动按 **⌘V**。

快捷键和登录自启可从菜单栏的「设置」调整。

## 本地运行

当前源码版本为 **0.1.0**，包含剪贴板历史、键盘搜索与回填、分类筛选和内容预览。

需要 Apple 芯片 Mac 和 Xcode。构建的最低系统目标为 macOS 15.0，目前候选包已在 macOS 26.6.2 上完成部分流程验证，macOS 15 和 27 的运行验证待完成。

在项目根目录运行以下命令，构建并启动应用。

```sh
make run
```

启动后可在 macOS 菜单栏找到「瞬贴」。也可以在 Xcode 中打开 `PasteFlick/PasteFlick.xcodeproj` 并运行 `PasteFlick`。
